# Daniyal Gulraiz — Web Developer Portfolio

A responsive personal portfolio website built with HTML, CSS and vanilla JavaScript. It includes a light/dark theme switcher and is ready for free static hosting with GitHub Pages.

## Files

- `index.html` — website content and structure
- `styles.css` — responsive layout and both colour themes
- `script.js` — theme switcher, saved theme preference, mobile menu and footer year
- `assets/daniyal-gulraiz.jpg` — optimized copy of the supplied portrait; the original brown kurta colour and genuine brick-wall background are retained
- `assets/Daniyal-Gulraiz-CV.pdf` — CV used by the Download CV links
- `assets/favicon.svg` — simple browser-tab icon

## Chromebook upload instructions

1. Download this ZIP file to your Chromebook.
2. Open the **Files** app, open **Downloads**, right-click the ZIP and choose **Extract all**.
3. Open the extracted `daniyal-portfolio` folder.
4. Sign in to [GitHub](https://github.com/) or create a free account.
5. Create a **Public** repository named `daniyal-gulraiz-portfolio`.
6. In the repository, choose **Add file → Upload files**.
7. Upload the *contents* of the extracted folder, not the outer folder itself. Make sure `index.html` is at the repository root and keep the `assets` folder with all its files.
8. Commit the files.
9. Open **Settings → Pages**.
10. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, and save.
11. GitHub Pages will publish the site at `https://YOUR-GITHUB-USERNAME.github.io/daniyal-gulraiz-portfolio/` after deployment completes.

Replace `YOUR-GITHUB-USERNAME` with your actual GitHub username.

## Before sharing publicly

- Check that your phone number and email are the details you want to make public.
- The project previews are illustrative CSS mockups, not screenshots of the original client websites.
- No unprovided GitHub, LinkedIn or live-project URLs have been invented. Add those links later when you have real profiles or project URLs to share.
- GitHub Pages can host this portfolio because it is static HTML, CSS and JavaScript. It cannot run a PHP application or provide a MySQL database; the PHP/MySQL project is shown as a project description only.

## Editing

You can edit `index.html`, `styles.css` and `script.js` directly on GitHub using the browser. Keep the relative folder structure and asset file names unchanged unless you also update the links in the HTML.


## Updating the portfolio later

You can change the profile photo, wording, skills and project previews later. To replace the portrait, upload a new image into `assets` and either keep the filename `daniyal-gulraiz.jpg` or update the image path in `index.html`. To update the CV, replace `assets/Daniyal-Gulraiz-CV.pdf` with the new PDF using the same filename.
